# 102-

프로젝트 개발을 위한 기본 저장소입니다.

## 시작하기

```sh
git clone https://github.com/hailyong5061-hub/102-.git
cd 102-
```

현재 애플리케이션 소스, 의존성, 빌드 및 테스트 명령은 등록되어 있지 않습니다.
기술 스택이 결정되면 필요한 도구 버전과 설치·실행·테스트 절차를 이 문서에 추가하세요.

## 기본 개발 지침

- 비밀 키와 인증 정보는 커밋하지 마세요. 필요한 환경 변수는 로컬 `.env` 파일로 관리하세요.
- 환경 변수 예시가 필요하면 실제 비밀 값 없이 `.env.example`을 작성하세요.
- 의존성을 추가할 때 사용하는 패키지 관리자의 잠금 파일을 함께 커밋하세요.
- 기존 홈페이지를 변경하는 작업은 별도의 요청과 변경으로 진행하세요.

이 초기 구성에는 홈페이지 파일이나 배포 설정이 포함되어 있지 않습니다.
